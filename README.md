# 小三數學大對戰

一個雙人實時對戰的數學比較遊戲，設計用於幫助小學三年級學生學習分數、重量、容量和長度的比較概念。

## 🎮 遊戲特色

- **雙人分屏對戰** - 左邊騎士 vs 右邊法師
- **實時計時** - 限時 2 分鐘的激烈競爭
- **職業升級系統** - 答對累積 5 題可解鎖進階職業頭銜
- **Combo 系統** - 連續答對獲得加分加成
- **50 道精選題目** - 涵蓋分數、重量、容量、長度四大類別
- **怪獸戰鬥機制** - 答對攻擊怪獸，答錯被反擊

## 📋 遊戲規則

### 基本流程
1. 玩家各自面對一隻怪獸
2. 選擇運算符 (`>`, `<`, `=`) 完成比較
3. 按「確定」提交答案
4. 答對扣怪獸 20 HP，答錯自己扣 10 HP
5. 怪獸 HP 歸零時生成新怪獸
6. 2 分鐘內擊敗最多怪獸的玩家獲勝

### 職業升級

**騎士系列**
- 見習騎士 → 初級騎士 → 中級騎士 → 高級騎士 → 主宰騎士 → 傳奇聖騎士

**法師系列**
- 見習法師 → 初級法師 → 中級法師 → 高級法師 → 主宰法師 → 傳奇大魔導師

## ⚙️ 遊戲配置

在 `game.js` 中的 `GAME_CONFIG` 物件可調整：

```javascript
const GAME_CONFIG = {
    GAME_DURATION: 120,           // 遊戲時間（秒）
    INITIAL_HP: 100,              // 初始 HP
    MONSTER_HP: 100,              // 怪獸 HP
    CORRECT_DAMAGE: 20,           // 正確答案傷害
    WRONG_DAMAGE: 10,             // 錯誤答案傷害
    CORRECT_TO_UPGRADE: 5,        // 答對幾題升級
    COMBO_THRESHOLD: 3            // Combo 顯示門檻
};
```

## 📊 題目資料庫

50 道精選題目分為四個類別：

| 類別 | 數量 | 範圍 |
|------|------|------|
| 分數 | 13 | 1/3 ~ 4/4 |
| 重量 | 12 | 300g ~ 7kg |
| 容量 | 13 | 500mL ~ 5L |
| 長度 | 12 | 50cm ~ 9m |

## 🎯 學習目標

- 理解分數大小比較
- 掌握重量單位換算 (g ↔ kg)
- 理解容量單位換算 (mL ↔ L)
- 掌握長度單位換算 (cm ↔ m)
